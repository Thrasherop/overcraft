# ===== How each game event is put together (build_asset_pack.py sounds). Minecraft plays one file per sound event, so
# the layers Overwatch plays together are mixed into one file per variant, at build time:
#   @<event> = <source>[@<delay s>][:<gain dB>] + <source>...   (layers separated by " + ", spaces included)
# Every variant of the first source gets a pick of each other source's variants. Sources not used by any rule are
# events of their own (voice lines). All mixes are made mono (Minecraft only places mono sounds) and kept below full
# scale (the sound research found hits, melee, climb start and Swift Step's cast clipping by up to +2.7 dB).
# "1P" events go to Kiriko's own player, "_3p" to everyone else (Overwatch's audiences 1 and 2).
